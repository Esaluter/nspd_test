# NSPD TEST WEB

Автономная веб-лаборатория сетевой диагностики НСПД и кадастрового поиска по одному адресу. Проект выделен из проверенной логики Bot 2 и не зависит от NEWS SUPER ANALYSER, Telegram, Google Sheets, AI-сервисов, очередей или корпоративной базы.

## Локальный запуск

Требуется Python 3.11.

```powershell
cd C:\Users\Admin\Desktop\nspd_test
python -m pip install -r requirements.txt
$env:NSPD_WEB_PASSWORD = "задайте-длинный-уникальный-пароль"
$env:NSPD_SECURE_COOKIE = "0"
python main.py
```

Откройте `http://127.0.0.1:8000`. Если `NSPD_WEB_PASSWORD` не задан, сервер слушает только `127.0.0.1` и печатает одноразовый случайный пароль при запуске. Пароль не записывается в файлы или журнал.

Автотесты не обращаются к НСПД:

```powershell
python -m pytest -q --basetemp .pytest_tmp
```

## BotHost

Параметры панели:

- платформа: Telegram (только формальный тип; Telegram API не используется);
- язык и версия: Python 3.11;
- регион: Россия (Москва);
- главный файл: `main.py`;
- внутренний порт: `8000` либо выбранное в панели значение;
- переменная `PORT`: платформа передаёт её автоматически, код использует `PORT` и запасной порт `8000`;
- `NSPD_WEB_PASSWORD`: обязательный длинный уникальный пароль;
- `NSPD_SECURE_COOKIE=1`: обязательно для публичного HTTPS-домена;
- собственный Dockerfile и Docker Compose не требуются.

Имя `PORT` сверено с [официальной документацией BotHost о доменах и портах](https://bothost.ru/docs/domains-and-ports). Порт в панели должен совпадать с внутренним портом приложения.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `NSPD_WEB_PASSWORD` | нет | пароль панели; без него доступ только с loopback |
| `NSPD_SECURE_COOKIE` | `0` | установить `1` за HTTPS reverse proxy |
| `PORT` | `8000` | HTTP-порт BotHost |
| `NSPD_CLIENT_TIMEOUT` | `10` | тайм-аут одного API-запроса, секунд |
| `NSPD_SEARCH_TIMEOUT` | `30` | общий лимит поиска, секунд |
| `NSPD_ATTEMPTS` | `2` | попытки одного варианта, максимум 3 |
| `NSPD_REQUEST_DELAY_SECONDS` | `1` | задержка между повторными попытками |
| `NSPD_MAX_CONCURRENT` | `2` | одновременные NSPD-операции, максимум 4 |

## Защита

- все API, кроме входа, требуют подписанную HttpOnly-сессию;
- изменяющие операции требуют CSRF-токен;
- пять неудачных входов блокируют новые попытки на 15 минут;
- поиск ограничен тремя запусками в минуту на сессию;
- одновременные NSPD-операции ограничены семафором;
- TLS всегда проверяет сертификат и имя хоста; `verify=False` отсутствует;
- HTTP-клиент не использует proxy-переменные окружения и не следует редиректам;
- секретоподобные поля в диагностике заменяются на `[REDACTED]`.

## Диагностика

События сохраняются в `diagnostics/events.jsonl`. В режиме debug полные ответы API сохраняются отдельными JSON-файлами после редактирования чувствительных полей. Файлы доступны для просмотра и скачивания только после авторизации. Реальные DNS/TCP/TLS/HTTP/API-проверки и поиски запускаются исключительно кнопками пользователя.
